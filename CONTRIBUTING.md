# Contributing

Thanks for contributing! This list follows the [Awesome manifesto](https://github.com/sindresorhus/awesome/blob/main/awesome.md).

## Adding an entry

- One link per line
- Format: `[Name](url) — Description.`
- Description starts with a capital letter, ends with a period
- Keep descriptions under 80 characters
- Group alphabetically within each section

## Quality bar

- Must be specifically useful for Vietnamese financial markets
- Active in the last 12 months (or clearly historical / educational)
- Free or has a free tier
- English or Vietnamese language

## PR process

1. Fork
2. Add your entry in the appropriate section
3. Open a PR with a one-line description of why it's useful
